# Soccer Schedule Maker

Use this soccer schedule maker when teams need a clear fixture list with fields, kickoff times, rest rounds, and home or away balance. It works best for youth leagues, rec tournaments, and short events where a spreadsheet would be easy to misread.

## Soccer scheduling details

Start by treating each field as a venue. Match length should include warmup, halftime, injury buffer, and the time needed for teams to leave the field. A 40-minute game often needs a longer published field block.

For a one-day soccer event, round robin is usually better when every team should get several games. A bracket is better after pool standings decide seeds.

## Build the first version

1. Enter one team or player per line.
2. Choose league fixtures or round robin for guaranteed games.
3. Set the number of fields you can actually use.
4. Add the first kickoff time and full field block length.
5. Generate, then check whether any team has an unfair rest pattern.

## Field and rest checks

- Rename courts to Field 1, Field 2, or the real field names before sharing.
- Check that no team appears in overlapping kickoff blocks.
- Add a break before playoffs if pool games determine bracket seeds.
- Keep bye rounds visible so coaches know when teams are resting.
- Publish tie-breakers before the first match, not after a standings tie.

## Common Questions

**Can I print this schedule?** Yes. Generate the schedule and use the Print control after checking court names, times, and byes.

**Can I export the schedule?** Yes. Use the CSV button when you want to edit the match list in a spreadsheet.

**Does the generator handle odd team counts?** Yes. Odd team counts create byes. Review those byes against travel time, rest time, and field availability.

**Should I randomize teams?** Randomize for a casual draw. Use entered order when standings, age groups, or seeds already matter.
