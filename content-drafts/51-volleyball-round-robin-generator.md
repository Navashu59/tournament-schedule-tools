# Volleyball Round Robin Generator

Use this volleyball round robin generator for pool play, club events, PE classes, and small tournaments where every team should get scheduled matches before standings or playoffs.

## Volleyball pool play setup

Volleyball round robins are usually court-limited. Enter teams, set the number of courts, and choose a match block that includes warmup, score reporting, and team changeover. If matches are best-of-three, do not use the same time block as a single timed set.

For multiple pools, generate one pool at a time. Then use the CSV export to combine pools into a master event sheet.

## Generate one pool

1. Enter one team or player per line.
2. Keep round robin selected.
3. Set court count from the actual playable courts.
4. Add first serve time and match block length.
5. Generate, then check byes, court rotation, and playoff handoff.

## Volleyball-specific checks

- Publish whether teams ref or line judge during byes.
- Keep court labels aligned with signs at the venue.
- Confirm whether standings use match wins, set wins, point differential, or head-to-head.
- Add a reset break before bracket play if pool results seed playoffs.
- Avoid hiding byes; teams often need them for officiating assignments.

## Common Questions

**Can I print this schedule?** Yes. Generate the schedule and use the Print control after checking court names, times, and byes.

**Can I export the schedule?** Yes. Use the CSV button when you want to edit the match list in a spreadsheet.

**Does the generator handle odd pools?** Yes. Odd team counts create byes, which you can use for rest or officiating.

**Should teams be randomized?** Randomize casual pools. Use entered order when seed balance or club separation matters.
